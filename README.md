# Bài tập lớn - Thiết kế website thiết kế nội thất  

## Giới thiệu  
Đây là BTL được làm theo nhóm, tôi phụ trách làm header, footer và 1 vài trang con

## Chức năng tôi làm  
- Thanh cuộn: giúp người dùng xem sản phẩm một cách mượt mà.  
- Tìm kiếm sản phẩm theo tên bằng JavaScript.  

## Cách chạy  
1. Clone repo này hoặc tải file về.  
2. Mở file **phongnl.html** bằng trình duyệt.  

## Công nghệ sử dụng  
- **HTML, CSS**: Xây dựng bố cục và giao diện.  
- **JavaScript**: Xử lý thanh cuộn và tìm kiếm sản phẩm.
